# Astrophysics & Data Science

Welcome to my scientific portfolio!

This repository contains personal projects developed with Python, focused on astronomical data analysis, astrophysics and cosmology, using publicly available scientific datasets.

My goal is to combine data science, statistical analysis and machine learning with astrophysical research.

##  Research Interests

- Galaxy formation and evolution
- Low Surface Brightness Galaxies (LSBGs)
- Ultra-Diffuse Galaxies (UDGs)
- Dark Matter
- Large-Scale Structure of the Universe
- Machine Learning applied to Astronomy
- Astronomical surveys and observational cosmology

##  Projects

### 01. Euclid DR1 – Galaxy Data Exploration
**Status:** In progress

Exploratory analysis of galaxy catalogues from the ESA Euclid mission.

Topics:
- Astronomical data retrieval using Python and ADQL
- Photometric properties and galaxy colours
- Photometric redshift analysis
- Statistical distributions and data visualization
- Galaxy population studies

**Dataset:** ESA Euclid Data Release 1

### 02. Ultra-Diffuse Galaxies
**Status:** Planned

Exploration of low surface brightness galaxies and ultra-diffuse galaxy candidates.

Topics:
- Surface brightness analysis
- Galaxy size and luminosity
- Image processing
- Morphological measurements

### 03. Galaxy Morphology
**Status:** Planned

Analysis of galaxy structures and morphological properties using astronomical imaging data.

### 04. Machine Learning for Astronomy
**Status:** Planned

Application of machine learning techniques to astronomical datasets, including galaxy classification and clustering.
